# NoPhishZone

**NoPhishZone** is an ethical hacking project designed to raise awareness about phishing attacks.  
It simulates a fake **Facebook login page**, captures credentials using PHP, and then redirects users to the real Facebook website.  

> ⚠️ This project is for **educational purposes only** and must be used responsibly.

---

---

## 📌 Features

- Fake Facebook login page
- Captures login credentials using PHP
- Redirects to the official Facebook website
- Runs on WampServer for local testing

---

## 🛠️ Requirements

- [WampServer](https://www.wampserver.com/en/) or any local server environment
- Basic understanding of HTML, PHP, and cybersecurity

---

## 💻 Installation

1. Download and install [WampServer](https://www.wampserver.com/en/).
2. Clone or [download this repository](https://github.com/abdulqadir-004/NoPhishZone).
3. Copy the project folder (`NoPhishZone`) into the `www` directory of WampServer.
4. Launch WampServer and open your browser.
5. Navigate to:  
   [`http://localhost`](http://localhost)
6. The fake Facebook login page will appear. Test it (for awareness purposes only).

---

## ⚠️ Usage

- This project **simulates** a phishing attack for ethical hacking training.
- Never deploy it on a public server or use it to deceive real users.
- Always verify URLs and ensure **HTTPS** before entering sensitive credentials.
